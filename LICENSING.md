- If you **distribute** DbExplorer, or software that contains it, you must make the complete corresponding source available under the AGPL-3.0.
- If you **modify** DbExplorer and let people use it **over a network**, for example in a web application, you must offer those users the source of your modified version (AGPL section 13).

You need a **commercial license** if you want to use DbExplorer without these conditions, for example to:

- ship it inside a closed-source product, or distribute it without releasing your source;
- run a modified version for users without offering them its source;
- comply with a company policy that does not allow AGPL-licensed software.

If you are unsure which applies to you, ask; this page is a summary, and the license texts are what bind.
